## Review Focus

스펙이 암시하지만 어느 과제의 테스트도 저절로 덮지 않는 입력들이다. 각 줄의
테스트를 그 코드를 가진 과제에 넣어 두었다.

1. **`updated_at` 이 `Z` 와 `+09:00` 로 섞여 오고 `note_count` 는 같은 경우** —
   사전식 비교는 더 이른 시각을 큰 값으로 골라 변경을 **놓친다**. 동료가 고친 내용
   위에 답글이 올라간다 → Task 1
2. **`local.reply` 가 공백만인 경우** — 전송 대상이 아니어야 하고 `pushed_hash` 도
   쓰지 않아야 한다. 빈 note 를 올리면 되돌릴 수 없다 → Task 3
3. **답글 본문이 코드 펜스·표·CRLF 를 담은 경우** — stdin 으로 간 바이트가 그대로
   여야 한다. 깨진 마크다운은 리뷰어가 읽는다 → Task 5
4. **서버 상태가 그대로인 채 `push` 를 두 번** — 두 번째는 쓰기 요청을 **하나도**
   보내지 않고 exit 0 이어야 한다 (PRD 의 "중복 전송 0건") → Task 5
5. **보낼 것이 하나도 없는 `push`** — "보낼 것이 없습니다" 와 exit 0. 빈 결과를
   실패로 보고하면 안 된다 → Task 6

- [ ] **Step 3: aware datetime 으로 비교한다**

`cli/src/mrq/discussions.py` 상단에 `import datetime as dt` 를 더하고, `_to_thread`
의 `updated_at=max(n["updated_at"] for n in notes)` 를 `updated_at=_latest_updated_at(notes)`
로 바꾼 뒤 아래를 추가한다.

```python
def _latest_updated_at(notes: list[dict]) -> str:
    """가장 늦은 `updated_at` 을 **원본 문자열 그대로** 돌려준다.

    문자열 `max()` 를 쓰면 안 된다 — GitLab 이 `Z` 와 `+09:00` 을 섞어 주면
    사전식 순서가 실제 시각과 어긋나고, 더 이른 시각이 "가장 늦은 것" 으로
    뽑힌다. 그러면 노트 수가 그대로인 채 본문만 수정된 스레드의 변경을 `push`
    가 놓치고(`cli.md` §9 3단계), 동료가 고친 내용 위에 답글이 올라간다.

    값을 정규화해 저장하지는 않는다. `server.updated_at` 은 서버 스냅샷의
    지문이고, `push` 는 같은 함수로 계산한 두 값을 **같음/다름**으로만 비교한다.
    """
    return max(notes, key=lambda note: _instant(note.get("updated_at")))["updated_at"]


def _instant(value: object) -> dt.datetime:
    """비교용 절대 시각. 파싱할 수 없으면 "가장 이른 것" 으로 둔다.

    `render.stamp` 와 별도인 이유는 폴백이 다르기 때문이다 — 표시 경로는 원본
    문자열을 그대로 보여주고, 여기서는 비교 가능한 값이 필요하다.
    """
    if not isinstance(value, str):
        return dt.datetime.min.replace(tzinfo=dt.timezone.utc)
    try:
        parsed = dt.datetime.fromisoformat(value)
    except ValueError:
        return dt.datetime.min.replace(tzinfo=dt.timezone.utc)
    return parsed if parsed.tzinfo is not None else parsed.astimezone()
```

`cli/src/mrq/conflict.py` 의 `plan_sync` 마지막에서, 반영 결과 기준으로 판정한다.

```python
def _todo_with_reply_warnings(
    review,
    parsed: mdparse.Parsed,
    applied: list[Applied],
) -> list[mdparse.Message]:
    """답글이 있는데 상태가 `todo` 인 스레드를 경고한다 (`cli.md` §5 MUST).

    `push` 는 `todo` 에 아무것도 하지 않는다(`data-model.md` §4.7). 사람은
    "답글을 썼으니 보내질 것" 으로 읽기 쉬운데 `status` 의 `push replies` 에도
    세어지지 않아 검토면에서 보이지 않는다. 동작은 바꾸지 않는다 — `[ ]` 로
    두고 초안을 적어 두는 것은 정상 워크플로다.
    """
    lines = {block.thread_id: block.line for block in parsed.blocks}
    result = {item.thread: (item.state, item.reply) for item in applied}
    out: list[mdparse.Message] = []
    for thread in review.threads:
        state, reply = result.get(thread.id, (thread.local.state, thread.local.reply))
        if state == "todo" and reply.strip():
            out.append(
                mdparse.Message(
                    lines.get(thread.id, 0),
                    f"{thread.id[:8]}: 답글이 있는데 상태가 `[ ]` 입니다 — "
                    "전송되지 않습니다. 보내려면 `[x]` 또는 `[~]` 로 바꾸세요",
                )
            )
    return out
```

`plan_sync` 의 `return applied, conflicts, warnings` 를 아래로 바꾼다.

```python
    warnings += _todo_with_reply_warnings(review, parsed, applied)
    return applied, conflicts, warnings
```

```python
def read_threads(text: str) -> dict[str, Thread]:
    """검증을 통과하는 json 에서만 스레드 **전체**를 돌려준다. 아니면 빈 dict.

    `read_previous` 로는 할 수 없는 일이 있다 — 그것은 `local` 과 `anchor` 만
    건지지만, 응답에서 사라진 스레드를 보존하려면 새 응답에 대응물이 없으므로
    `server`·`position`·`notes` 까지 이전 것을 그대로 가져와야 한다 (§4.10).

    손상·구버전 json 에서는 보존을 포기한다. 그 경로의 복구는 `read_previous`
    의 최선 노력이고, 거기서 건진 `local` 은 붙일 스레드가 없으면 쓸 곳이 없다.
    """
    try:
        data = json.loads(text)
    except json.JSONDecodeError:
        return {}
    if not isinstance(data, dict) or data.get("schema_version") != SCHEMA_VERSION:
        return {}
    try:
        validate(data)
    except jsonschema.ValidationError:
        return {}
    return {thread.id: thread for thread in Review.from_dict(data).threads}
```

```python
def _carry_missing(root, iid: int, threads: list[model.Thread]) -> list[model.Thread]:
    """응답에서 사라진 스레드 중 미전송 작업이 있는 것을 보존한다 (§4.10).

    미전송 작업이 없는 스레드는 그대로 제거한다 — 보존해서 표시할 로컬 상태가
    없으므로 남기면 md 와 `status` 에 설명할 수 없는 항목이 쌓인다.
    """
    path = store.review_json_path(root, iid)
    if not path.is_file():
        return threads
    present = {thread.id for thread in threads}
    carried = []
    for thread_id, previous in model.read_threads(path.read_text(encoding="utf-8")).items():
        if thread_id in present:
            continue
        if not (previous.local.reply.strip() or previous.local.state != "todo"):
            continue
        previous.server.missing = True
        carried.append(previous)
        print(
            f"⚠ {thread_id[:8]} 스레드가 서버 응답에서 사라졌습니다 — 미전송 작업이 "
            "있어 보존합니다. `push` 는 전송하지 않으므로 답글을 직접 옮기세요.",
            file=sys.stderr,
        )
    return threads + carried
```

```python
"""`push` 의 사전 판정. 네트워크도 파일도 만지지 않는다 (docs/spec/cli.md §8·§9).

`status` 의 `push` 블록과 `push` 의 판정은 **같은 함수**에서 나와야 한다(MUST).
두 곳에 따로 구현하면 "검토면은 9건이라고 했는데 8건 갔다" 가 조용히 생기고,
숫자가 틀리는 순간 전송 직전 검토면 자체가 의미를 잃는다. `status` 는 스냅샷
없이, `push` 는 스냅샷을 들고 부르므로 두 결과의 차이는 `server-changed` 하나다.
"""

from __future__ import annotations

import hashlib
from dataclasses import dataclass, field

from mrq import model

# 보낼 수 없다고 판정된 이유. 열거값이며 `--json` 과 `--dry-run` 이 같은 값을
# 쓴다 — 소비자가 메시지 문자열을 파싱하게 만들지 않는다 (cli.md §9 MUST NOT).
SKIP_REASONS = ("no-reply", "not-resolvable", "server-changed", "server-missing")


def body_hash(reply: str) -> str:
    """전송 본문의 sha256. `local.pushed_hash` 의 기준이다.

    해시 대상은 **실제로 stdin 에 넣는 바이트**다 (cli.md §9). 정규화하지
    않는다 — `v:` 해시(렌더 정규형)와는 다른 목적이다.
    """
    return hashlib.sha256(reply.encode()).hexdigest()


@dataclass
class Decision:
    """스레드 하나에 대해 이번 `push` 가 할 일."""

    thread: str
    reply: str = ""  # 보낼 본문. "" 면 답글 전송 없음
    resolve: bool = False
    skip: str | None = None  # SKIP_REASONS 중 하나
    record_hash: str | None = None  # 전송 없이 기록할 pushed_hash (2차 방어)


@dataclass
class Plan:
    decisions: list[Decision] = field(default_factory=list)
    warnings: list[dict] = field(default_factory=list)

    @property
    def replies(self) -> int:
        return sum(1 for d in self.decisions if d.reply)

    @property
    def resolves(self) -> int:
        return sum(1 for d in self.decisions if d.resolve)

    @property
    def skip(self) -> int:
        return sum(1 for d in self.decisions if d.skip is not None)

    def targets(self) -> list[Decision]:
        """실제로 쓰기 작업이 있는 결정만."""
        return [d for d in self.decisions if d.reply or d.resolve or d.record_hash]


def plan(
    review: model.Review,
    *,
    snapshot: list[model.Thread] | None = None,
    resolve: str = "auto",
    force: bool = False,
) -> Plan:
    """무엇을 보낼지 정한다. `snapshot` 은 `discussions.to_threads` 의 결과다.

    `snapshot=None` 은 "서버를 보지 않았다" 는 뜻이고 `server-changed` 판정만
    빠진다. `resolve` 는 `auto | skip | require` 이며 `require` 의 권한 검사는
    호출자가 전송 전에 한다(exit 1) — 여기서는 `auto` 와 같게 다룬다.
    """
    out = Plan()
    fresh = {t.id: t for t in snapshot} if snapshot is not None else None
    pending_resolves = 0

    for thread in review.threads:
        local = thread.local
        has_reply = bool(local.reply.strip()) and local.state in ("done", "replied")
        wants_resolve = (
            local.state == "done" and not thread.server.resolved and resolve != "skip"
        )
        if not (has_reply or wants_resolve):
            continue

        decision = Decision(thread=thread.id)

        if has_reply:
            if not thread.server.repliable:
                decision.skip = "no-reply"
                out.warnings.append({"thread": thread.id, "reason": "no-reply"})
            elif local.pushed_hash == body_hash(local.reply):
                # 1차 방어. 이미 보낸 본문이다 — 조용히 생략한다.
                pass
            else:
                decision.reply = local.reply

        if wants_resolve:
            if not thread.server.resolvable:
                decision.skip = decision.skip or "not-resolvable"
                out.warnings.append({"thread": thread.id, "reason": "not-resolvable"})
            else:
                pending_resolves += 1
                decision.resolve = review.me.can_resolve

        # 로컬에서 이미 아는 제약이 먼저다. 그 판정은 스냅샷 없이 부르는
        # `status` 와 결과가 같아야 한다.
        if thread.server.missing:
            decision.skip = "server-missing"
            decision.reply, decision.resolve, decision.record_hash = "", False, None
            out.warnings.append({"thread": thread.id, "reason": "server-missing"})
        elif fresh is not None:
            _judge_against_server(decision, thread, fresh.get(thread.id), force=force)
            if decision.skip == "server-missing":
                out.warnings.append({"thread": thread.id, "reason": "server-missing"})

        if decision.reply or decision.resolve or decision.skip or decision.record_hash:
            out.decisions.append(decision)

    out.warnings += _standing_warnings(review, pending_resolves)
    return out


def _judge_against_server(
    decision: Decision,
    thread: model.Thread,
    current: model.Thread | None,
    *,
    force: bool,
) -> None:
    """스냅샷이 있을 때만 하는 판정 (cli.md §9 3단계)."""
    if current is None:
        # 보낼 곳이 없다. `--force` 로도 보내지 않는다 — `--force` 가 무시하는
        # 것은 "서버가 바뀌었다" 뿐이다 (결정 0011).
        decision.skip = "server-missing"
        decision.reply, decision.resolve, decision.record_hash = "", False, None
        return
    changed = (
        current.server.updated_at != thread.server.updated_at
        or current.server.note_count != thread.server.note_count
    )
    if changed and not force:
        decision.skip = "server-changed"
        decision.reply, decision.resolve = "", False
        return
    if decision.reply and _already_posted(current, decision.reply):
        # 2차 방어. POST 는 성공했는데 `pushed_hash` 기록 직전에 죽은 경우다.
        # 해시를 기록해야 한다(MUST) — 건너뛰기만 하면 다음 실행도 매번
        # 스냅샷에 의존하고, 그 note 가 스냅샷에서 빠지면 중복 전송이 된다.
        decision.record_hash = body_hash(decision.reply)
        decision.reply = ""
    if decision.resolve and current.server.resolved:
        decision.resolve = False


def _already_posted(current: model.Thread, reply: str) -> bool:
    """스냅샷에 같은 본문의 내 note 가 있는가.

    양쪽을 `strip()` 해 느슨하게 본다 — GitLab 이 끝 공백을 다듬어 돌려주면
    엄격 비교가 중복 전송을 허용한다. 느슨한 쪽의 실패(전송을 한 번 빼먹고
    사용자가 `status` 에서 본다)가 엄격한 쪽(같은 답글을 두 번 올린다)보다 싸다.
    """
    needle = reply.strip()
    return any(note.mine and note.body.strip() == needle for note in current.notes)


def _standing_warnings(review: model.Review, pending_resolves: int) -> list[dict]:
    """전송 대상과 무관하게 사용자가 알아야 하는 것들."""
    out: list[dict] = []
    for thread in review.threads:
        if thread.local.reply.strip() and thread.local.state == "todo":
            # push 는 todo 에 아무것도 하지 않는다(§4.7). replies 에도 세어지지
            # 않으므로 검토면에서 보이지 않는 자리다.
            out.append({"thread": thread.id, "reason": "todo-with-reply"})
        if thread.local.push_error is not None:
            # push 자신의 출력은 그 순간에만 보인다. 이것이 없으면 403 이
            # json 안에만 남는다 (cli.md §8).
            out.append({"thread": thread.id, "reason": "push-failed"})
    if pending_resolves and not review.me.can_resolve:
        out.append({"thread": None, "reason": "no-resolve-permission"})
    if review.mr_state != "opened":
        out.append({"thread": None, "reason": "mr-not-opened"})
    return out
```

```python
def status_payload(review: model.Review) -> dict:
    local = {"todo": 0, "done": 0, "replied": 0, "skipped": 0}
    anchors = {"exact": 0, "fuzzy": 0, "stale": 0}
    for thread in review.threads:
        local[thread.local.state] += 1
        # `location` 이 null 인 스레드(§4.9)와 서버에서 사라진 스레드(§4.10)는

        # 잘 재배치했는가" 의 측정값이 아니다.
        if (
            thread.location is not None
            and thread.location.confidence in anchors
            and not thread.server.missing
        ):
            anchors[thread.location.confidence] += 1

    sheet = push.plan(review)
    return {
        "iid": review.iid,
        "title": review.title,
        "mr_state": review.mr_state,
        "head_sha": review.diff_refs.head_sha,
        "pulled_at": review.pulled_at,
        "rendered_at": review.rendered_at,
        "threads": {
            "total": len(review.threads),
            "unresolved": sum(1 for t in review.threads if not t.server.resolved),
            "resolved_on_server": sum(1 for t in review.threads if t.server.resolved),
        },
        "local": local,
        "anchors": anchors,
        "push": {
            "replies": sheet.replies,
            "resolves": sheet.resolves,
            "skip": sheet.skip,
        },
        "warnings": sheet.warnings,
    }
```

```python
"""GitLab 에 **쓰는** 유일한 지점. docs/spec/cli.md §3 의 엔드포인트 표.

읽기 메타 조회는 `mr.py`, 스레드 목록은 `discussions.py` 다. 쓰기를 한 파일에
모아 두는 이유는 `gitcmd` 래퍼와 같다 — "바깥으로 나가는 요청은 전부 여기"
여야 감사할 수 있고, `reanchor`/`status` 가 네트워크를 안 탄다는 것을 증명해 준
장치가 그것이다.
"""

from __future__ import annotations

from typing import Any

from mrq import glab
from mrq.mr import PROJECT


def post_reply(iid: int, discussion_id: str, body: str) -> Any:
    """기존 스레드에 답글을 단다.

    본문은 `-F body=@-` 로 stdin 에 넣는다(MUST). 인자로 넘기면 길이 제한과
    셸 인용 문제가 생기고, 표와 코드 블록이 섞인 답글이 깨진다.
    """
    return glab.api(
        f"{PROJECT}/merge_requests/{iid}/discussions/{discussion_id}/notes",
        method="POST",
        body=("body", body),
    )


def resolve(iid: int, discussion_id: str) -> Any:
    """스레드를 resolve 한다. `resolved` 는 불리언이어야 하므로 `fields` 다."""
    return glab.api(
        f"{PROJECT}/merge_requests/{iid}/discussions/{discussion_id}",
        method="PUT",
        fields={"resolved": "true"},
    )
```

새 파일을 만들고, `commands/sync.py` 에서 아래를 그대로 가져온다 —

```python
"""`review.md` → `review.json` 반영의 핵심. docs/spec/cli.md §5.

`sync` 와 `push` 가 같은 코드를 쓴다. `push` 는 **자기 락 안에서** 이것을
불러야 한다(MUST) — 락을 두 번 잡으면 그 틈에 에디터의 `sync` 가 끼어들어
검토면에서 본 것과 다른 것을 보낸다. 그래서 여기서는 락을 잡지 않는다.
"""

from __future__ import annotations

import json
import sys
from dataclasses import dataclass, field
from pathlib import Path

from mrq import SCHEMA_VERSION, conflict, mdparse, model, reanchor, store, surface, threads
from mrq.errors import SchemaVersionError, UsageError


@dataclass
class Outcome:
    review: model.Review | None = None
    applied: list[conflict.Applied] = field(default_factory=list)
    warnings: list[mdparse.Message] = field(default_factory=list)
    errors: list[mdparse.Message] = field(default_factory=list)
    conflicts: list[conflict.Conflict] = field(default_factory=list)
    stats: reanchor.Stats | None = None


def perform(
    root: Path,
    iid: int,
    path: Path,
    *,
    prefer: str | None = None,
    only_refs: tuple[str, ...] = (),
) -> Outcome:
    """md 를 json 에 반영하고 재앵커링한다. 호출자가 락을 잡고 있어야 한다.

    에러·충돌이면 **아무것도 쓰지 않고** 그 사실만 담아 돌려준다. 보고와 종료
    코드는 호출자(`sync` 또는 `push`)의 몫이다.
    """
    md_path = store.review_md_path(root, iid)
    if not md_path.is_file():
        raise UsageError(
            "review.md 가 없습니다. `mrq pull --render` 로 복원하세요. "
            "(review.json 은 온전합니다 — 답글과 상태는 그대로 있습니다)"
        )

    review = model.loads(path.read_text(encoding="utf-8"))
    parsed = mdparse.parse(md_path.read_text(encoding="utf-8"))

    if parsed.meta.schema is not None and parsed.meta.schema != SCHEMA_VERSION:
        raise SchemaVersionError(
            f"review.md 의 schema 가 {parsed.meta.schema} 입니다 (이 mrq 는 {SCHEMA_VERSION})."
        )
    if parsed.meta.iid is not None and parsed.meta.iid != iid:
        raise UsageError(
            f"다른 MR 의 review.md 입니다 (파일 iid {parsed.meta.iid}, 대상 {iid}). "
            "아무것도 쓰지 않았습니다."
        )
    if parsed.meta.head and parsed.meta.head != review.diff_refs.head_sha:
        print(
            f"⚠ review.md 의 head 가 {parsed.meta.head[:7]} 이고 현재 head 는 "
            f"{review.diff_refs.head_sha[:7]} 입니다. 재앵커링이 처리합니다.",
            file=sys.stderr,
        )

    errors = sorted(
        parsed.errors + _swallowed_anchor_errors(review, parsed), key=lambda m: m.line
    )
    if errors:
        return Outcome(errors=errors)

    only_ids = tuple(threads.resolve_ref(review, ref).id for ref in only_refs)
    applied, conflicts, extra = conflict.plan_sync(
        review, parsed, prefer=prefer, only=only_ids
    )
    if conflicts:
        return Outcome(conflicts=conflicts)

    at = surface.now()
    by_id = {t.id: t for t in review.threads}
    for item in applied:
        local = by_id[item.thread].local
        local.state = item.state
        local.reply = item.reply
        local.touched_by = "md"
        local.touched_at = at

    have_git = reanchor.ensure_commits(
        root, iid, review.source_branch, review.diff_refs, allow_fetch=False
    )
    stats = reanchor.reanchor_all(root, review, have_git=have_git)
    surface.write(root, review, include_resolved=False)
    return Outcome(
        review=review,
        applied=applied,
        warnings=parsed.warnings + extra,
        stats=stats,
    )
```

`_swallowed_anchor_errors`, `report_errors`, `report_conflicts` 는 `commands/sync.py`

```python
"""`mrq sync`. docs/spec/cli.md §5. 네트워크를 쓰지 않는다."""

from __future__ import annotations

import json
import sys

from mrq import mdsync, store


def run(args) -> int:
    context = store.open_review(on_branch_change="fail")
    root, iid, path = context.root, context.iid, context.path

    with store.review_lock(root, iid):
        outcome = mdsync.perform(
            root,
            iid,
            path,
            prefer=args.prefer,
            only_refs=tuple(args.thread or ()),
        )
    if outcome.errors:
        return mdsync.report_errors(outcome.errors, json_mode=args.json)
    if outcome.conflicts:
        return mdsync.report_conflicts(iid, outcome.conflicts, json_mode=args.json)

    for warning in outcome.warnings:
        print(f"review.md:{warning.line}: {warning.message}", file=sys.stderr)

    if args.json:
        json.dump(
            {
                "iid": iid,
                "applied": [item.as_dict() for item in outcome.applied],
                "warnings": [
                    {"line": w.line, "message": w.message} for w in outcome.warnings
                ],
                "anchors": outcome.stats.as_dict(),
            },
            sys.stdout,
            ensure_ascii=False,
        )
        sys.stdout.write("\n")
    else:
        changed = sum(1 for item in outcome.applied if item.reply_changed)
        print(
            f"synced: {len(outcome.applied)} 스레드 반영 (답글 {changed}건) "
            f"· reanchored: {outcome.stats}"
        )
    return 0
```

```python
"""`mrq push`. docs/spec/cli.md §9.

스레드마다 결과를 즉시 json 에 쓴다(MUST) — 중간에 죽어도 재실행으로 복구되어야
한다. 중복 전송 방지는 `pushed_hash` 와 서버 스냅샷의 동일 본문 두 겹이고,
`push.plan` 이 그 판정을 들고 있다.
"""

from __future__ import annotations

import argparse
import json
import sys

from mrq import discussions, mdsync, model, push, store, surface, transport
from mrq.commands import pull as pull_command
from mrq.errors import GlabError, MrqError, UsageError


def run(args) -> int:
    context = store.open_review(on_branch_change="fail")
    root, iid, path = context.root, context.iid, context.path

    with store.review_lock(root, iid):
        outcome = mdsync.perform(root, iid, path)
        if outcome.errors:
            return mdsync.report_errors(outcome.errors, json_mode=args.json)
        if outcome.conflicts:
            return mdsync.report_conflicts(iid, outcome.conflicts, json_mode=args.json)
        review = outcome.review
        for warning in outcome.warnings:
            print(f"review.md:{warning.line}: {warning.message}", file=sys.stderr)

        if args.resolve == "require" and not review.me.can_resolve:
            raise UsageError(
                "resolve 권한이 없습니다 (--resolve require). 아무것도 전송하지 않았습니다. "
                "`--resolve auto` 로 답글만 보낼 수 있습니다."
            )

        # 전체를 한 번만 조회한다(MUST). 스레드별 GET 은 N+1 이다.
        snapshot = discussions.to_threads(discussions.fetch(iid), review.me.username)
        sheet = push.plan(
            review, snapshot=snapshot, resolve=args.resolve, force=args.force
        )
        failures = _send(root, review, sheet)

    _repull(iid)
    return _report(sheet, failures, json_mode=args.json)


def _send(root, review: model.Review, sheet: push.Plan) -> list[dict]:
    by_id = {t.id: t for t in review.threads}
    failures: list[dict] = []
    for decision in sheet.targets():
        thread = by_id[decision.thread]
        if decision.record_hash:
            _mark_sent(thread, decision.record_hash)
        if decision.reply:
            try:
                transport.post_reply(review.iid, thread.id, decision.reply)
            except GlabError as exc:
                failures.append(_record_failure(thread, "reply", exc))
            else:
                _mark_sent(thread, push.body_hash(decision.reply))
        if decision.resolve:
            try:
                transport.resolve(review.iid, thread.id)
            except GlabError as exc:
                failures.append(_record_failure(thread, "resolve", exc))
                if exc.status == 403:
                    # 사전 판정이 틀릴 수 있다(커스텀 역할, 그룹 상속 권한, MR
                    # 잠금). 강등하면 다음 push 에서 이 스레드는 애초에 resolve
                    # 대상이 아니므로 재시도 루프가 상태 기계 차원에서 닫힌다.
                    thread.local.state = "replied"
            else:
                thread.server.resolved = True
                thread.local.push_error = None
        # 스레드 하나가 끝날 때마다 json 을 flush 한다(MUST). md 는 그리지
        # 않는다 — 재pull 이 한 번 그린다 (data-model.md §5.2 가 거짓 충돌이
        # 생기지 않는 이유다).
        store.atomic_write_text(
            store.review_json_path(root, review.iid), model.dumps(review)
        )
    return failures


def _mark_sent(thread: model.Thread, digest: str) -> None:
    thread.local.pushed_hash = digest
    thread.local.reply = ""
    thread.local.push_error = None
    thread.local.touched_by = "push"
    thread.local.touched_at = surface.now()


def _record_failure(thread: model.Thread, op: str, exc: GlabError) -> dict:
    thread.local.push_error = {
        "op": op,
        "status": exc.status,
        "reason": exc.reason,
        "retryable": exc.retryable,
        "at": surface.now(),
        "message": str(exc),
    }
    return {
        "thread": thread.id,
        "op": op,
        "status": exc.status,
        "reason": exc.reason,
        "retryable": exc.retryable,
    }


def _repull(iid: int) -> None:
    """서버 스냅샷을 다시 받고 md 를 한 번 그린다 (§9 5단계).

    락 밖에서 부른다 — `pull` 이 자기 락을 잡는다. 실패해도 종료 코드는 전송
    결과를 따른다(MUST): 전송 결과는 이미 json 에 있고, 그것을 네트워크 실패로
    덮으면 사용자가 "안 갔다" 로 읽는다.
    """
    namespace = argparse.Namespace(mr=iid, all=False, render=False, no_render=False)
    try:
        pull_command.run(namespace)
    except MrqError as exc:
        print(
            f"⚠ 전송 후 재pull 이 실패했습니다 ({exc}). 전송 결과는 review.json 에 "
            "기록되어 있습니다 — `mrq pull` 을 다시 실행하세요.",
            file=sys.stderr,
        )


def _report(sheet: push.Plan, failures: list[dict], *, json_mode: bool) -> int:
    sent_replies = sheet.replies - sum(1 for f in failures if f["op"] == "reply")
    sent_resolves = sheet.resolves - sum(1 for f in failures if f["op"] == "resolve")
    if json_mode:
        json.dump(
            {
                "pushed": {"replies": sent_replies, "resolves": sent_resolves},
                "failures": failures,
            },
            sys.stdout,
            ensure_ascii=False,
        )
        sys.stdout.write("\n")
    else:
        print(f"pushed: 답글 {sent_replies}건 · resolve {sent_resolves}건")
        for failure in failures:
            retry = "재실행하면 다시 시도합니다" if failure["retryable"] else "재시도하지 않습니다"
            print(
                f"✗ {failure['thread'][:8]} {failure['op']} 실패 "
                f"({failure['reason']}, status {failure['status']}) — {retry}",
                file=sys.stderr,
            )
    return 4 if failures else 0
```

```python
def confirm(message: str, *, force: bool) -> None:

        raise UsageError("중단했습니다.")
```

```python
_VERSION = re.compile(r"\d+\.\d+\.\d+")


@dataclass
class Check:
    name: str
    ok: bool
    detail: str
    hint: str = ""

    def line(self) -> str:
        mark = "✓" if self.ok else "✗"
        tail = f"  → {self.hint}" if (not self.ok and self.hint) else ""
        return f"{self.name:<13} {mark} {self.detail}{tail}"


def run(args) -> int:
    checks = list(_checks())
    for check in checks:
        print(check.line())
    return 0 if all(c.ok for c in checks) else 1


def _checks():
    yield _glab_version()

    try:
        user_id, username = mr.whoami()
    except MrqError as exc:
        yield Check("glab auth", False, str(exc), "`glab auth login` 으로 로그인하세요")
        return
    yield Check("glab auth", True, f"{username} (id {user_id})")

    try:
        project, can_resolve = mr.project_info()
    except MrqError as exc:
        yield Check(
            "remote",
            False,
            str(exc),
            "origin 이 GitLab 리포인지, 그 프로젝트에 접근 권한이 있는지 확인하세요",
        )
        return
    yield Check("remote", True, f"origin → {project}")

    try:
        info = mr.detect(root)
    except MrqError as exc:
        yield Check("MR", False, str(exc), "`mrq pull --mr <iid>` 로 지정할 수 있습니다")
        yield _storage(root)
        return
    yield Check("MR", True, f"!{info.iid} (source_branch {info.source_branch})")

    try:
        refs = mr.diff_refs(info.iid)
    except MrqError as exc:
        yield Check("head_sha", False, str(exc))
    else:

        yield Check(

        "프로젝트 권한을 올리거나 `--resolve skip` 을 쓰세요",

    try:

        )
    except FileNotFoundError:
        return Check("glab", False, "설치되어 있지 않습니다", "https://gitlab.com/gitlab-org/cli")
    found = _VERSION.search(proc.stdout or "")
    # 버전 번호로 기능을 분기하지 않는다(MUST NOT). 표시용이다.
    return Check("glab", proc.returncode == 0, f"v{found[0]}" if found else "버전 확인 불가")

        f"{directory}" + ("" if ignored else " (.gitignore 없음)"),
        "`mrq pull` 이 `.mrq/.gitignore` 에 `*` 를 씁니다",
```

```python
def read_current(root: Path) -> int | None:
    """`.mrq/current` 가 가리키는 iid. 읽을 수 없으면 `None`.

    손으로 만든 비숫자 포인터에서 터지면 안 된다 — 모든 명령이 이 함수를
    지나므로 예외가 나면 사용자의 탈출구가 `rm -rf .mrq/` 뿐이다.
    """
    current = mrq_dir(root) / "current"
    if current.is_dir():
        name = current.resolve().name
        return int(name) if name.isdigit() else None
    if current.is_file():
        text = current.read_text(encoding="utf-8").strip()
        return int(text) if text.isdigit() else None
    return None
```

```python
from __future__ import annotations

import shutil
import sys

from mrq import glab, model, prompt, store
from mrq.errors import MrqError
from mrq.mr import PROJECT


def run(args) -> int:
    root = store.repo_root()
    # 모든 명령의 시작에서 보장한다 (data-model.md §1 MUST). `doctor` 만
    # 예외다 — 진단이 상태를 만들면 "없음" 을 진단할 수 없다.
    store.ensure_mrq_gitignore(root)
    wanted = _wanted(args)
    current = store.read_current(root)
    targets = []

    for directory in sorted(store.mrq_dir(root).glob("*/review.json")):
        iid = int(directory.parent.name)
        try:
            data = glab.api(f"{PROJECT}/merge_requests/{iid}")
        except MrqError as exc:
            print(f"⚠ !{iid} 의 상태를 확인할 수 없습니다 ({exc}) — 건너뜁니다.", file=sys.stderr)
            continue
        state = (data or {}).get("state")
        if state not in wanted:
            continue
        targets.append((iid, state, _unsent(root, iid)))

    if not targets:
        print("제거할 것이 없습니다.")
        return 0

    for iid, state, unsent in targets:
        suffix = f" — 미전송 작업 {unsent}건" if unsent else ""
        print(f"!{iid} ({state}){suffix}")
    if args.dry_run:
        return 0

    pending = sum(unsent for _, _, unsent in targets)
    if pending:
        prompt.confirm(
            f"미전송 작업이 {pending}건 남아 있습니다. 제거하면 답글을 복구할 수 없습니다.",
            force=args.force,
        )

    for iid, _, _ in targets:
        shutil.rmtree(store.review_dir(root, iid))
        if iid == current:
            # 끊어진 심링크를 남기지 않는다(MUST).
            store.clear_current(root)
    print(f"removed: {len(targets)}개")
    return 0


def _wanted(args) -> set[str]:
    """플래그가 없으면 merged 와 closed 둘 다 (§11)."""
    if not args.merged and not args.closed:
        return {"merged", "closed"}
    return {name for name, on in (("merged", args.merged), ("closed", args.closed)) if on}


def _unsent(root, iid: int) -> int:
    """전송하지 않은 작업이 있는 스레드 수. 손상 json 은 0 으로 둔다."""
    path = store.review_json_path(root, iid)
    try:
        review = model.loads(path.read_text(encoding="utf-8"))
    except MrqError:
        return 0
    return sum(
        1
        for thread in review.threads
        if thread.local.reply.strip() or thread.local.state != "todo"
    )
```

```python
def _run_draft(root, review: model.Review, sheet: push.Plan, args) -> list[dict]:
    """draft 생성과 발행. 결정 0012.

    중복 방어는 `GET draft_notes` 한 번이 전부다(MUST) — `pushed_hash` 가 아직
    없으므로 두 겹이 아니다. 조회가 실패하면 draft 를 만들지 않는다: 방어 없이
    만들면 재실행이 draft 를 복제하고, 복제된 draft 는 mrq 가 지울 수 없다.
    """
    drafts = transport.list_drafts(review.iid)  # GlabError → exit 5
    failures: list[dict] = []
    if args.draft:
        failures += _create_drafts(root, review, sheet, drafts)
    if args.publish:
        failures += _publish(root, review, drafts, force=args.force)
    return failures


def _create_drafts(root, review: model.Review, sheet: push.Plan, drafts: list[dict]) -> list[dict]:
    existing = {(d.get("discussion_id"), (d.get("note") or "").strip()) for d in drafts}
    by_id = {t.id: t for t in review.threads}
    failures: list[dict] = []
    for decision in sheet.targets():
        if not decision.reply and not decision.resolve:
            continue
        thread = by_id[decision.thread]
        body = decision.reply or thread.local.reply
        if (thread.id, body.strip()) in existing:
            continue
        try:
            transport.create_draft(
                review.iid, thread.id, body, resolve=decision.resolve
            )
        except GlabError as exc:
            failures.append(_record_failure(thread, "draft", exc))
            store.atomic_write_text(
                store.review_json_path(root, review.iid), model.dumps(review)
            )
        else:
            print(f"draft {thread.id[:8]} {'(+resolve)' if decision.resolve else ''}")
    return failures


def _publish(root, review: model.Review, drafts: list[dict], *, force: bool) -> list[dict]:
    """`bulk_publish` 는 내 pending draft **전부**를 발행한다 (선택적 발행이 없다)."""
    bodies = {
        (t.id, t.local.reply.strip()): t for t in review.threads if t.local.reply.strip()
    }
    mine = [d for d in drafts if (d.get("discussion_id"), (d.get("note") or "").strip()) in bodies]
    foreign = [d for d in drafts if d not in mine]
    if foreign:
        prompt.confirm(
            f"mrq 가 만들지 않은 draft 가 {len(foreign)}건 있습니다. "
            "bulk_publish 는 내 draft 전부를 발행하므로 그것들도 함께 공개됩니다.",
            force=force,
        )
    if not drafts:
        print("발행할 draft 가 없습니다.")
        return []

    try:
        transport.bulk_publish(review.iid)
    except GlabError as exc:
        thread = review.threads[0]
        failure = _record_failure(thread, "publish", exc)
        store.atomic_write_text(
            store.review_json_path(root, review.iid), model.dumps(review)
        )
        return [failure]

    # 발행된 본문의 해시를 기록하고, **현재 값이 그 본문과 같을 때만** 비운다
    # (결정 0012) — draft 를 만든 뒤 md 에서 고친 답글을 지우면 그 수정이 사라진다.
    for draft in drafts:
        thread = next(
            (t for t in review.threads if t.id == draft.get("discussion_id")), None
        )
        if thread is None:
            continue
        note = draft.get("note") or ""
        thread.local.pushed_hash = push.body_hash(note)
        if thread.local.reply.strip() == note.strip():
            thread.local.reply = ""
        thread.local.push_error = None
        thread.local.touched_by = "push"
        thread.local.touched_at = surface.now()
    store.atomic_write_text(store.review_json_path(root, review.iid), model.dumps(review))
    print(f"published: draft {len(drafts)}건")
    return []
```

`push_error.op` 의 `draft`·`publish` 는 스키마에 이미 있다 (설계 커밋).
