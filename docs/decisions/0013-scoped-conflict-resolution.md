# 0013. 충돌 해소도 스레드 단위로 섞을 수 있어야 한다

2026-10-14 · 계획 4 전 과제

## 맥락

[0002](0002-per-thread-conflict-detection.md)가 충돌 **판정**을 스레드 단위로
정했지만, 해소 수단은 `--prefer md|json [--thread ID]...` 로 **호출당 방향 하나**
였다. 계획 4 의 Emacs 충돌 버퍼(`editor.md` §3.4)를 설계하다 그것이 §3.4 와
모순인 것이 드러났다 — §3.4 는 스레드마다 `m`(md 채택) / `j`(json 유지) 를
고르라고 한다.

스레드 A 는 md, B 는 json 으로 고르면 어떤 순서로도 빠져나갈 수 없다.
`data-model.md` §5.3 이 "충돌이 하나라도 남으면 아무것도 쓰지 않고 exit 3" 을
MUST 로 두기 때문이다:

```
mrq sync --prefer md   --thread A   →  B 가 여전히 충돌  →  exit 3, 아무것도 안 씀
mrq sync --prefer json --thread B   →  A 가 여전히 충돌  →  exit 3, 아무것도 안 씀
```

## 버린 대안 셋

- **`mrq state`/`reply` 로 json 쪽을 먼저 확정한다** — 그 명령들이 `review.md` 를
  재렌더하므로(`cli.md` §10 MUST) md 쪽으로 고르려던 스레드의 편집이 지워진다
- **에디터가 md 블록을 json 값으로 직접 고쳐 쓴다** — 렌더러를 elisp 에 복제하는
  일이고 `editor.md` §1-1 의 근거("md 파서를 Python 한 곳에만")를 정면으로 깬다
- **`--pick ID=dir` 을 별도 플래그로 추가한다** — `--prefer`+`--thread` 를 완전히
  흡수하지만 `--prefer` 단독은 흡수하지 못한다. `--prefer md` 의 값은 "일괄" 이
  아니라 **"id 를 타이핑하지 않아도 된다"** 이고, 그것이 터미널의 사람과 AI
  에이전트가 쓰는 경로다 (0008 이 두 번 언급한다). 결국 플래그가 둘로 남는다

## 선택

`--prefer` 에 **선택적 스코프 접두사**를 붙여 플래그 하나로 합친다.
`--thread` 는 삭제한다 — `--prefer` 없이는 의미가 없던, 혼자 서지 못하는
플래그였다.

```
mrq sync [--json] [--prefer [ID=]md|json]...
```

널리 쓰이는 관용구다 — `RUST_LOG=debug` 대 `RUST_LOG=mycrate=trace`,
python `-W error` 대 `-W error::DeprecationWarning:mymod`.

해소 규칙은 **좁은 스코프가 순서와 무관하게 이긴다. 같은 스코프 안에서는 뒤가
이긴다.** 위치 기반 fold(뒤가 앞을 무조건 덮음)도 검토했고 버렸다 — fold 는
"앞의 개별 지정을 뒤의 전역 항목이 지운다" 는 모서리를 만드는데,
`chmod`·`.gitignore`·CSS·`RUST_LOG` 가 전부 반대로 동작하므로 반대로 기대하는
사람이 생긴다. 스코프 우선은 그 모서리가 없고 구현도 더 짧다 — fold 는 전역
항목을 만날 때마다 쌓인 개별 지정을 비워야 한다.

`--prefer md` 를 `--prefer all=md` 로 바꿔 문법을 완전히 균일하게 만드는 안도
검토했다. 유일한 이득이 synopsis 의 깔끔함인데 `[ID=]` 표기가 같은 것을 주면서
공통 경우를 길게 만들지 않는다 — 충돌 자체가 드물고 혼합 방향은 더 드물다.

## 결과

- 에디터의 충돌 버퍼는 **모든 충돌에 방향이 정해진 뒤 한 번의 `sync`** 를 부른다.
  키를 누를 때마다 부르면 첫 키부터 실패한다. `editor.md` §3.4 가 이 모양이다
- 부분 해소는 여전히 불가능하다. 0002 와 §5.3 의 all-or-nothing 은 그대로다
- 앞의 `ID=` 지정을 뒤에 `--prefer md` 를 붙여 **취소할 수 없다.** 취소하려면 그
  `ID=` 를 반대 방향으로 다시 줘야 한다 — 명시적으로 고른 것이 나중 항목에
  조용히 지워지지 않는 쪽이 맞다
- 스코프 없는 값이 스레드 접두사와 겹치면 exit 1. discussion id 는 SHA1
  16진수라 도달 불가지만, 가정을 불변식으로 고정해 깨졌을 때 조용한 오동작이
  아니라 에러가 나게 한다
